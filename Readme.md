# Customer Segmentation Using Machine Learning

## 📌 About the Project

This project focuses on analyzing customer behavior and identifying different customer segments using Machine Learning.

The **K-Means Clustering** algorithm is used to group customers based on their income, age, spending habits, purchasing patterns, and other characteristics.

## 🎯 Project Objectives

- Analyze customer purchasing behavior.
- Identify different customer segments.
- Understand customer spending patterns.
- Apply K-Means Clustering.
- Generate meaningful business insights.

## 🤖 Algorithm Used

**K-Means Clustering**

The algorithm groups customers into 4 clusters based on their characteristics and purchasing behavior.

## 📈 Key Findings

- Analyzed differences in customer purchasing behavior.
